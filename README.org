#+TITLE: sumi - cairo-elisp native renderer for NeLisp
#+STARTUP: showall

* What this is

=sumi= is the native rendering layer used by =dev/newDTW-nelisp=.
The active path is Elisp from the game runtime through the frame feeder and the
renderer source:

#+begin_example
  NeLisp/Elisp game runtime
      -> pure-elisp live feeder / binary packer
      -> cairo-elisp AOT renderer source
      -> GTK4 window executable
#+end_example

The repository keeps the active cairo-elisp renderer source only. Older
alternative backend and shell-host experiments have been removed from the active
tree.

* Active Component

- =backends/cairo-elisp/= - Elisp renderer sources, AOT build entrypoint, live
  renderer, dump renderer, and renderer fixtures.

* Build

#+begin_src sh
  emacs -Q --batch -l backends/cairo-elisp/build-live.el
#+end_src

The resulting =sumi-sprite-live.exe= is deployed by the newDTW live launcher to
=C:/Users/kuroz/AppData/Local/Temp/sumi-sprite-live.exe=.

* Windows Setup

The AOT renderer links against GTK4 libraries from MSYS2. The build expects
=pkg-config= and =gcc= in =C:/msys64/mingw64/bin= unless =MINGW_BIN= overrides it.
